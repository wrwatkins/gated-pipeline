## Delivery process

Read .gated-pipeline/START.md when delivering a non-trivial change. It routes all assistants to the same process, project configuration, current gate and evidence contract. Only load the current role's procedure.

Use `gated-pipeline context --gate=N` to index files before reading. Reuse already-read unchanged instructions within the same context; reacquire required content after a fresh session or compaction. The CORE owns the freshness rules.

For project policies and specialized context, use docs/AI_REPOSITORY.md as an index; read only applicable area guidance before acting.

Record the actual author, reviewer and verifier in PR evidence. Tool names are separate from models; unknown model/run fields are explicitly null. Never claim self-review as independent.
